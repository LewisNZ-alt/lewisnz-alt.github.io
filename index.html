Open Source • Batch & PowerShell

Clean Windows 11,
Zero Bloatware.

A transparent, lightweight batch utility that strips away pre-installed consumer apps while keeping core Windows services and updates completely intact.

Get the Script Star on GitHub

System-Safe Targeting

Strictly removes consumer UWP apps (Bing, Solitaire, GetHelp, etc.) without touching Windows Defender, Store, or Update components.

Automatic Restore Point

Creates a local Windows System Restore checkpoint prior to execution so you can roll back changes in seconds.

100% Auditable Code

No obfuscated binaries or external downloads. Every command is plain-text Batch and PowerShell you can inspect before running.

Quick Tip: Make sure System Protection is enabled on your C: drive before running, and always right-click the saved .bat file and select Run as administrator.

Source Script

debloat.bat 
@echo off
Title Windows 11 Safe Debloat Script
echo ========================================================
echo Running Windows 11 Safe Debloat Script...
echo ========================================================
echo.

:: Check for Administrator privileges
net session >nul 2>&1
if %errorLevel% neq 0 (
    echo Failure: Please run this script as an Administrator!
    pause
    exit /b
)

echo Creating a System Restore Point just in case...
powershell -Command "Enable-ComputerRestore -Drive 'C:\'; Checkpoint-Computer -Description 'BeforeDebloat' -RestorePointType 'MODIFY_SETTINGS'"

echo.
echo Removing consumer bloatware apps safely...

powershell -Command ^
"$apps = @(^
    'Microsoft.3DBuilder',^
    'Microsoft.BingNews',^
    'Microsoft.BingWeather',^
    'Microsoft.GetHelp',^
    'Microsoft.Getstarted',^
    'Microsoft.MicrosoftOfficeHub',^
    'Microsoft.MicrosoftSolitaireCollection',^
    'Microsoft.People',^
    'Microsoft.SkypeApp',^
    'Microsoft.Todos',^
    'Microsoft.YourPhone',^
    'Microsoft.ZuneMusic',^
    'Microsoft.ZuneVideo'^
);^
foreach ($app in $apps) {^
    Get-AppxPackage -AllUsers -Name $app | Remove-AppxPackage -ErrorAction SilentlyContinue^
    Get-AppXProvisionedPackage -Online | Where-Object DisplayName -eq $app | Remove-AppxProvisionedPackage -Online -ErrorAction SilentlyContinue^
    Write-Host 'Processed: $app' -ForegroundColor Green^
}"

echo.
echo ========================================================
echo Debloating process complete! 
echo It is recommended to restart your computer now.
echo ========================================================
pause
